UNILIFE OS — UNIFIED REMINDER CENTRE UPDATE

Frontend update:
- Removes the separate in-app class reminder popup.
- Keeps class schedules in Calendar; class notification settings/calendar notifications are otherwise untouched.
- Combines eligible assignment and examination reminders into one Reminder Centre popup.
- Sorts reminders into Urgent, High Priority, and Upcoming.
- Adds one Dismiss All action for the currently eligible reminder batch.

Install:
1. Extract this ZIP.
2. Replace the matching files in your GitHub Pages project with this package.
3. Commit and push the updated files.
4. No Apps Script backend change is required for this frontend-only popup update.

Note:
Dismissal state is stored in this browser's local storage, matching the existing reminder dismissal approach.
